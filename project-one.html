Project 01

First Portfolio Site

The first version of this portfolio, hand built while working through the HTML and CSS lessons on The Odin Project. It is kept online as a snapshot of where I started.

  • HTML
  • CSS
  • Flexbox
Open the live site Source code

Overview

I started this as a place to practise everything I was picking up from The Odin Project, beginning with plain headings and lists and slowly turning it into a full page with a navigation bar, project cards and a contact section. Every layout decision was made with flexbox, since that was the part I most wanted to understand.

Features

  • Sticky navigation bar linking to each section, with smooth scrolling.
  • Full height sections laid out with nested flex containers.
  • Custom fonts loaded from the project with @font-face.
  • Project and contact cards built as reusable blocks.

What I learned

Flexbox finally clicked here, in particular how a container and its items share out space. I also learned the hard way that long selector chains like .body .flex-container .title-section .title-content become difficult to override, which is why the current site uses short class names instead.

Deploying it taught me the rest: relative asset paths, why file name casing matters on a live server even when it does not on Windows, and how to use git branches so an old version can stay online while I rebuild.
